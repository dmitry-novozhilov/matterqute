# Дизайн-бриф matterqute

matterqute — десктопный клиент Mattermost на Qt 6 для ежедневной рабочей переписки. Логика готова, интерфейс собран из стандартных виджетов Qt. Нужны визуальная система и макеты, которые можно перенести в Qt без потерь.

| Платформа | Сервер | Окно по умолчанию | Язык интерфейса |
|---|---|---|---|
| Linux, Qt 6.8 Widgets (Go + MIQT) | Mattermost 11.6, свёрнутые треды (Collapsed Reply Threads) | 1100×720 | русский |

Скриншоты текущего состояния лежат рядом, в `img/`. Их стоит приложить вместе с этим файлом.

## Запрос

Сделай дизайн-систему и макеты экранов для десктопного клиента Mattermost «matterqute» по этому брифу. Текущие скриншоты приложены картинками.

Реализация — Qt 6 Widgets и QSS, поэтому держись ограничений из раздела «Что умеет Qt»: без теней в ленте, без анимаций, текст сообщений — подмножество HTML 4.

На выходе:

1. Токены: цвета для светлой и тёмной темы, шрифты и кегли, отступы, радиусы, рамки — в px и HEX.
2. Компоненты со всеми состояниями из раздела «Экраны и состояния».
3. Макеты экранов в окне 1280×800 и в узком 900×600.

Интерфейс на русском, данные для макетов — из раздела «Данные для макетов». Открытые вопросы покажи вариантами, а не решай молча.

## Что нужно от дизайна

### Токены

- Палитра для светлой и тёмной темы: фон, поверхности, текст основной и вторичный, акцент, выделение строки, подсветка своего упоминания, рамки, семантические цвета для алертов (good, warning, danger).
- Типографика: семейства (свои шрифты можно встроить в приложение), кегли и начертания для имени канала, автора, текста, времени, служебных подписей, кода.
- Шкала отступов, радиусы, толщины рамок.
- Размеры: высота строки сайдбара, ширины колонок, пределы превью картинок, размер эмодзи в тексте и в реакциях.

### Компоненты и макеты

- Компоненты со всеми состояниями из раздела «Экраны и состояния»: строка сайдбара, сообщение, реакция, вложения, поле ввода, кнопки, поля, плашки, карточка пользователя.
- Макеты: вход (форма, код MFA, ошибка), главное окно с каналом, с открытым тредом, список тредов, карточка пользователя, лента с вложениями и сообщением интеграции, загрузка, пустой канал, нет связи.
- Набор монохромных SVG-иконок: тип канала (открытый, приватный, личка, группа), треды, ответ, реакция, прикрепить, открыть, сохранить, закрыть, статус пользователя.

## Экраны и состояния

Всё, что уже работает, плюс то, что появится в ближайших этапах (помечено «новое»). Каждое состояние должно быть в макетах или в компонентах.

### Вход

Сервер, логин (email или имя пользователя), пароль. Поле кода MFA появляется, только когда сервер его попросил.

Состояния: пустая форма; подключаемся по сохранённой сессии; входим…; код MFA; неверный логин или пароль; неверный код; сервер недоступен + «Повторить»; сессия истекла.

### Главное окно

Три колонки: сайдбар, канал, панель треда (открывается справа). Строка состояния: своё имя и соединение. Меню: выйти из аккаунта, выход.

Состояния: в сети; нет соединения, переподключаемся; тред закрыт; тред открыт.

### Сайдбар

Сверху «Треды» (при свёрнутых тредах), затем группы по командам (каналы по алфавиту) и «Личные сообщения» (свежие сверху). Тип канала: открытый, приватный, личка, группа.

Состояния строки: обычный; непрочитанный; с упоминаниями (счётчик); выбранный; наведение; заглушённый; личка с собой «(вы)»; новое — статус собеседника.

### Шапка канала

Имя с типом канала, назначение, заголовок канала (в нём бывают разметка и ссылки).

Состояния: только имя; с назначением; с заголовком.

### Лента

Новые снизу, история подгружается при прокрутке вверх. Сообщения одного автора подряд (меньше 5 минут) идут без повторного заголовка.

Состояния: загрузка; ошибка загрузки; пустой канал; подгрузка истории; новое — разделитель дней; новое — отметка «новые сообщения».

### Сообщение

Автор, время, текст с разметкой, вложения, реакции, ответы. Контекстное меню: ответить в треде, реакция, копировать текст.

Состояния: с заголовком; продолжение; системное; изменено; корень треда «N ответов»; ответ в канале (без свёрнутых тредов); упоминает меня; новое — аватар.

### Реакции

Эмодзи и число. Подсказка: кто поставил. «+» открывает 12 быстрых эмодзи. Кастомные эмодзи сервера — картинкой.

Состояния: чужая; своя; наведение; кастомный эмодзи; «+».

### Вложения

Картинки — превью, клик открывает целиком. Остальное — строкой. «Открыть» только для безопасных типов, остальным — только «Сохранить…».

Состояния: маленькая картинка; большая картинка; превью грузится; файл; файл только сохранить; новое — GIF с анимацией; новое — видео с плеером.

### Сообщение интеграции

Так пишут боты (Grafana и др.): цветная полоса, автор, заголовок-ссылка, текст с разметкой, поля в одну или две колонки, подпись.

Состояния: good; warning; danger; свой цвет; без полей; только fallback-текст.

### Поле ввода

Кнопка 📎, многострочный ввод: Enter отправляет, Shift+Enter переносит строку. Файлы ещё можно перетащить или вставить картинку из буфера. У каждого канала и треда свой черновик.

Состояния: пусто; текст; несколько строк; файл грузится; файл загружен; ошибка загрузки; «дождитесь загрузки файлов»; неактивно.

### Панель треда

«Тред · #канал», кнопка закрыть, корневое сообщение и ответы, поле ответа.

Состояния: загрузка; открыт; ошибка.

### Список тредов

При свёрнутых тредах: треды, на которые подписан пользователь. Канал и автор, первая строка, число ответов, время последнего.

Состояния: прочитан; новые ответы; упоминания; пусто.

### Карточка пользователя (новое)

Открывается по клику на @имя: имя, @username, статус, должность, кнопка «Написать».

Состояния: в сети; отошёл; не беспокоить; не в сети; это я.

### Следующий этап (новое)

Системные уведомления, значок в трее со счётчиком, несколько серверов в одном окне.

Состояния: уведомление; трей — есть упоминания; переключатель серверов.

## Сообщение: что бывает в тексте

Разметка Mattermost: CommonMark и GFM. Перевод строки — это перенос строки. HTML в тексте показывается как есть, текстом.

- Заголовки трёх уровней, жирный, курсив, зачёркнутый.
- Списки, нумерованные списки, чек-листы.
- Таблицы, цитаты, код строкой и блоком.
- Ссылки и голые адреса.
- **@упоминания.** Свои и `@channel`, `@all`, `@here` подсвечиваются. Клик откроет карточку пользователя.
- **~каналы** — ссылкой, клик открывает канал.
- **:эмодзи:** — системные символом из цветного шрифта, кастомные сервера картинкой (сейчас 20 px).
- **Картинки по ссылке** (`![](url)`) пока показываются ссылкой.

## Что умеет Qt

Интерфейс — Qt Widgets, стили — QSS (подмножество CSS). Макет, который опирается на недоступное, при переносе развалится, поэтому границы важнее вкуса.

### Можно

- Цвета, фон, градиенты, полупрозрачность.
- Рамки, в том числе по отдельным сторонам, и скругления у виджетов.
- Внутренние отступы, фиксированные и минимальные размеры.
- Свои шрифты, встроенные в приложение.
- Состояния: наведение, нажатие, выбран, неактивен, фокус.
- SVG-иконки, перекрашиваемые кодом; круглые аватары.
- Светлая и тёмная палитра, переключение по системе.

### Нельзя или дорого

- Тени: только эффект на отдельный виджет, в длинной ленте это тормозит.
- Размытие, CSS-переходы и анимации. Анимации только кодом, по минимуму.
- Flex и grid: раскладки — строки и колонки с растяжкой.
- Произвольное наложение элементов поверх ленты.

### Текст сообщения — отдельный случай

Текст рисуется движком Qt rich text, это подмножество HTML 4. Всё, что вокруг текста (реакции, файлы, картинки, кнопки), — обычные виджеты, им доступно всё из QSS.

| Элемент текста | Можно | Нельзя |
|---|---|---|
| Фрагмент (упоминание, код строкой) | цвет, фон, шрифт, начертание, подчёркивание | скругления, рамка, внутренние отступы: подсветка только прямоугольником |
| Абзац, заголовок | отступы сверху и снизу, цвет, выравнивание | рамка с одной стороны |
| Цитата, блок кода | фон и полоса через ячейку таблицы | скругления блока, тень |
| Таблица | рамки ячеек одним цветом, фон ячеек, отступы в ячейках | `border-collapse`: в Qt 6.8 рамки пропадают целиком |
| Картинка в тексте (эмодзи) | фиксированный размер | выравнивание по базовой линии тонко не настроить |

## Обратная связь пользователя

После первых дней работы с клиентом. Пункты для дизайна — первые, остальные влияют на ощущение от интерфейса.

- **Картинки слишком мелкие.** Сейчас всё вписывается в 360×240. Небольшие картинки не уменьшать вовсе, крупные вписывать в ширину ленты с пределом по высоте. Нужны размеры.
- **Видео — со встроенным плеером:** превью, кнопка воспроизведения, полоса прогресса, звук, на весь экран.
- **GIF анимировать**, сейчас показывается статичный кадр.
- **Клик по @имени открывает карточку пользователя** со ссылкой «Написать», а не сразу переписку.
- Эмодзи чёрно-белые. Это ошибка выбора шрифта, исправим в коде; макеты рисовать с цветными эмодзи.
- Лента иногда моргает белым. Это ошибка перерисовки, исправим в коде.
- Сообщения будут грузиться заранее, в фоне. Индикаторы загрузки останутся только для старой истории.

## Открытые вопросы

Решает владелец проекта. Дизайну стоит показать варианты.

- **Формат времени.** Сейчас у каждого сообщения полное `2026-11-01 08:14:04` — так у владельца принято для таймстампов по умолчанию. В чатах обычно время `08:14` и разделители дней, полное время в подсказке. Нужны оба варианта.
- **Аватары** у сообщений и в сайдбаре: есть или нет.
- **Плотность ленты:** компактная, как сейчас, или просторная; возможно, переключатель.
- **Тёмная тема:** только по системе или ещё и вручную.
- **Сайдбар:** дерево команд, как сейчас, или как в Mattermost (переключатель команд слева, категории «Избранное», «Каналы», «Личные»).
- **Где переключатель серверов**, когда их станет несколько.
