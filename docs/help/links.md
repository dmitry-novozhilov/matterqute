# Ссылки на сообщения: из браузера и в приложении

## Что умеет Matterqute

- Ссылка на сообщение, канал или личку своего сервера, нажатая внутри Matterqute, открывается здесь же: нужный канал, сообщение прокручено и подсвечено, ответ в треде — ещё и в панели треда. Ссылки на другие добавленные серверы переключают на них. Остальные ссылки открываются в браузере.
- Ссылку на сообщение можно скопировать: правый клик по сообщению → «Копировать ссылку на сообщение». Это такая же ссылка, как в веб-клиенте: `https://сервер/команда/pl/…`.
- Ссылки `mattermost://…` из браузера открываются в Matterqute. Если оно уже запущено, ссылку получает запущенное окно, второе не открывается.

## Как настроить открытие из браузера

1. Один раз выполните `./matterqute --install` (и ещё раз, если перенесли или пересобрали бинарник в другом месте). Команда ставит ярлык в меню приложений и делает Matterqute обработчиком ссылок `mattermost://`. В конце она пишет, какое приложение теперь открывает такие ссылки, — там должно быть `matterqute`.
2. Перезапустите браузер, если он был открыт.

Проверить без браузера (подставьте свой сервер и команду):

```
xdg-open 'mattermost://mm.example.com/команда/channels/town-square'
```

Должен открыться Matterqute на этом канале.

## Что происходит в браузере

Когда вы открываете ссылку на сервер Mattermost не из самого веб-клиента (из почты, из другого сайта, вставив в адресную строку), сервер показывает страницу выбора: «Открыть в настольном приложении» или «Открыть в браузере». Текст на ней всегда про «приложение Mattermost» — это страница сервера, она не знает, какое приложение у вас стоит.

1. Нажмите «Открыть в настольном приложении».
2. Браузер спросит, каким приложением открыть ссылку. Если стоит и официальный клиент Mattermost, он может оказаться предложенным первым — выберите в этом окне Matterqute (у браузеров там есть возможность выбрать другое приложение) и, если хотите, отметьте, чтобы браузер запомнил выбор.

## Если страница выбора больше не появляется

Веб-клиент Mattermost показывает её только один раз и запоминает это в хранилище сайта в браузере; потом ссылки сразу открываются в веб-версии. Чтобы страница появилась снова:

1. Откройте сайт сервера в браузере, нажмите F12 → «Консоль».
2. Выполните:

   ```js
   Object.keys(localStorage).filter(k => /landing/i.test(k)).forEach(k => { console.log(k, localStorage.getItem(k)); localStorage.removeItem(k) })
   ```

   Команда покажет и удалит запись `__landingPageSeen__` (и запомненный выбор, если он есть).
3. Откройте ссылку на сообщение в новой вкладке — страница выбора появится.

Страницу выбора можно выключить и на сервере (в консоли администратора — настройка страницы перехода в настольное приложение); тогда браузер всегда открывает веб-версию.

## Если ссылки открывает другое приложение

Посмотрите, что считает обработчиком система:

```
xdg-mime query default x-scheme-handler/mattermost
gio mime x-scheme-handler/mattermost
```

Обе команды должны назвать `matterqute.desktop`. Если нет — выполните `./matterqute --install` ещё раз; запись хранится в `~/.config/mimeapps.list`.
