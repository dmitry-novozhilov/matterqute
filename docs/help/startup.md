# Запуск и работа без связи

При запуске Matterqute сразу показывает то, что было на экране при выходе: каналы, счётчики, последние сообщения каждого канала и лички. Пока вы смотрите, приложение сверяется с сервером: приходит написанное за то время, пока оно было закрыто, обновляются счётчики, исправленные и удалённые сообщения. Обычно это занимает секунду-две.

Если сервер недоступен, окно всё равно откроется с последними сообщениями — их можно читать. Вверху будет плашка «Нет соединения»; как только связь появится, всё обновится само.

## Сообщения без связи

Писать можно и без связи: отправленное сообщение сразу появится в ленте с пометкой «Не отправлено — уйдёт, когда появится связь» и уйдёт само, как только связь вернётся, — по порядку, в каналы и треды, куда писали. То же, если связь пропала прямо во время отправки. Передумали — «Удалить» под сообщением. Если сервер откажет (например, канал успели отправить в архив), под сообщением будет причина, «Повторить» и «Удалить». Неотправленное переживает перезапуск приложения, но не выход из аккаунта. Файлы без связи не прикрепить: они загружаются на сервер сразу.

Если сессию закрыли на сервере (вышли со всех устройств, сменили пароль), после проверки появится страница входа.

Последние сообщения хранятся на диске в каталоге кэша (`~/.cache/matterqute`), доступном только вам. «Файл → Выйти из аккаунта» и «Сервер → Удалить сервер…» их стирают.
